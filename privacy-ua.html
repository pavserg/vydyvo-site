Політика конфіденційності

Останнє оновлення: липень 2026 року

Дякуємо, що користуєтеся Vydyvo.

Ця Політика конфіденційності пояснює, які дані використовує застосунок Vydyvo та з якою метою.

Які дані ми збираємо

Для використання Vydyvo не потрібно створювати обліковий запис або надавати персональні дані, такі як ім'я, адреса електронної пошти чи номер телефону.

Ваші закладки, оцінки, відгуки та інші дані застосунку зберігаються локально на вашому пристрої.

Аналітика та звіти про збої

Для покращення роботи застосунку Vydyvo використовує такі сторонні сервіси:

  • Firebase Analytics — для аналізу використання застосунку та вдосконалення його функціональності.
  • Firebase Crashlytics — для автоматичного збору звітів про збої та діагностичної інформації, що допомагає виявляти й виправляти помилки.

Ці сервіси можуть збирати технічну інформацію, зокрема:

  • модель пристрою;
  • версію операційної системи;
  • версію застосунку;
  • мову та регіон пристрою;
  • анонімну статистику використання;
  • журнали збоїв і діагностичну інформацію.

Ці дані використовуються виключно для покращення стабільності, продуктивності та якості роботи застосунку.

Дані про фільми та серіали

Vydyvo отримує інформацію про фільми, серіали, акторів і режисерів через API TMDB (The Movie Database) під час пошуку та перегляду контенту.

Цей застосунок використовує API TMDB, але не схвалений і не сертифікований TMDB.

Передача даних

Vydyvo не продає та не передає ваші персональні дані третім особам.

Дані, які обробляються сервісами Firebase, використовуються відповідно до політики конфіденційності Google.

Ваші права

Ви можете припинити використання застосунку в будь-який момент, видаливши його зі свого пристрою.

За потреби ви також можете керувати налаштуваннями конфіденційності та аналітики через налаштування свого пристрою, якщо такі можливості підтримуються операційною системою.
